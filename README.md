# Sport Style — אימונים ומוזיקה חכמה

אפליקציית Android בעברית לריצה, להליכה מהירה ולהרפייה, עם ממשק ספורטיבי כהה ונגיעות ירוק־ליים.

## מה כלול
- מסך בית עם סיכום פעילות יומי: מרחק, זמן וקלוריות משוערות.
- טיימר אימון, מדידת מרחק באמצעות GPS ומד צעדים במכשירים שתומכים בחיישן ובהרשאה המתאימה.
- ספריית מוזיקה מקומית; קובצי השירים נשמרים במכשיר דרך אחסון מקומי של האפליקציה.
- ניתוח BPM מקומי משוער והצעת שירים לפי מצב: ריצה, הליכה מהירה או הרפייה.
- נגן מלא, מיקס חכם ומסך גלילה של קטעי 15 שניות עם מעבר להשמעת השיר המלא.
- טיפים לחימום, שתייה, טכניקה והתאוששות.

## בניית APK
GitHub Actions מוגדר לבנות APK בכל דחיפה לענף `sport-style`. לאחר הצלחת הבנייה, ה־APK מועלה גם כארטיפקט של הריצה וגם לקובץ Release בשם Sport Style.

הפרויקט נמצא בתיקייה `sport-style/`. כדי לבנות מקומית נדרשים JDK 17 ו־Android SDK:
```bash
cd sport-style
gradle assembleDebug
```

## מגבלות חשובות
- האפליקציה מנתחת מאפיינים אקוסטיים ומעריכה BPM; זיהוי שם של שיר לפי מנגינה כמו Shazam דורש שירות זיהוי חיצוני שלא מחובר לפרויקט.
- השירים מגיעים מהקבצים שהמשתמש בוחר במכשיר. לא כלול קטלוג מוזיקה סטרימינג, ואין כאן חשבון Spotify או חיבור ל־Spotify.
- BPM, מרחק, צעדים וקלוריות הם אומדנים התלויים בקובץ, בחיישנים ובתנאי הקליטה.
- נגן המוזיקה שומר קבצים בספרייה מקומית של האפליקציה; ניקוי נתוני האפליקציה עשוי למחוק את הספרייה.

## פרטיות
ניתוח השירים מתבצע מקומית במכשיר, והשירים אינם מועלים לשרת על ידי האפליקציה.
