# GameOffline — גיים אופליין

אפליקציית Android בעברית עם 10 משחקים מקומיים, ללא צורך בחיבור לאינטרנט.

## המשחקים
- 2048
- זיכרון
- נחש
- חפרפרת
- ציפור קופצת
- סיימון
- מגדל
- מקש הבזק
- פונג
- שובר לבנים

## בנייה והורדה
הפרויקט נבנה אוטומטית ב-GitHub Actions בכל עדכון לקבצים שבתיקייה הזו. פתחו את לשונית **Actions**, בחרו את הריצה האחרונה בשם **Build GameOffline APK**, ובתחתית דף הריצה הורידו את קובץ ה-artifact בשם `GameOffline-debug-apk`. לאחר חילוץ ה-ZIP, קובץ ההתקנה הוא `app-debug.apk`.

המשחקים נטענים מנכסי האפליקציה המקומיים. לאחר התקנה אין צורך באינטרנט כדי לשחק.

הערה: ה-APK שמתקבל דרך Actions הוא build מסוג debug, שנחתם אוטומטית על ידי Android Gradle Plugin; הוא לא חתום כמפתח הפצה קבוע.
