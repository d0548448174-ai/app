# Music AI Offline

אפליקציה מקומית ליצירת מוזיקה חדשה באמצעות AI.

- יצירת מוזיקה מטקסט
- בחירת ז'אנר: Pop, Rock, Jazz, Classical, Electronic, Hip-Hop, Ambient, Cinematic, Reggae, Latin
- בחירת מצב רוח
- אורך יצירה
- Seed ליצירה שונה בכל פעם
- נגן מובנה
- שמירה כ-MP3
- לאחר הורדת המודל, היצירה מתבצעת מקומית

הגרסה משתמשת ב-MusicGen Small, מודל של 300M פרמטרים, כדי להיות קלה יותר להרצה מקומית.

## התקנה ב-Windows
1. התקן Python 3.11.
2. הפעל install.bat.
3. הפעל run.bat.
4. בפעם הראשונה יש להמתין להורדת המודל. לאחר מכן אפשר לעבוד ללא אינטרנט.

## חומרה
מומלץ NVIDIA GPU. גם CPU אפשרי אך יצירת מוזיקה תהיה איטית מאוד.

בדוק את רישיון MusicGen והמודל לפני שימוש מסחרי.
