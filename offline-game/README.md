# אופליין גיים — מדוזה כחולה

אפליקציית Android עם שמונה משחקים עצמאיים הפועלים מתוך נכסים מקומיים, ללא הרשאת אינטרנט:

1. חתול רץ
2. שובר לבנים
3. קפיצת חלל
4. פוצץ בועות
5. זיכרון
6. סודוקו
7. מרוץ מכוניות
8. איקס עיגול

המשחקים, הניקוד ועיצוב הממשק נטענים מקובץ HTML מקומי בתוך WebView. אין בקשות רשת בזמן משחק.

## Build
ה-workflow ב-GitHub Actions בונה את משימת assembleDebug של מודול offline-game ומעלה את קובץ ה-APK כ-Release asset.
