# Playback Studio — פלייבק סטודיו

אפליקציית Android מקומית שמקליטה קול או טוענת קובץ שמע, מזהה בקירוב את קו המנגינה ומנגנת אותו מחדש בכלים סינתטיים: כינורות, פסנתר ותופים.

## יכולות
- הקלטה מהמיקרופון או בחירת קובץ שמע מהמכשיר.
- ניתוח מקומי של גובה הצלילים והצגת מפת המנגינה.
- בחירה בין כינורות, פסנתר, תופים או שילוב מלא.
- שינוי קצב וגובה צליל.
- השמעה וייצוא ל-WAV.

## הערה על הדיוק
הגרסה משתמשת בזיהוי גובה צליל מונופוני. הקלטה של שירה/זמזום יחיד וברור תיתן תוצאה טובה יותר משיר מלא שיש בו כבר כמה כלים וקולות. הצלילים מופקים בסינתזה מקומית, ולא מדגימות אולפן.

## Build

Artifact: `playback-studio-apk`

הקוד והתהליך פועלים ללא שירות עיבוד חיצוני.
