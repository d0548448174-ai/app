# GameStation Hub

Landscape Android game launcher with a polished console-style library.

Built-in games:
- Neon Rush
- Starfall
- Brick//Break
- Cyber Match
- Orbit Run

Features:
- Landscape-first console UI
- Five built-in offline arcade games
- Game detail screen
- High-score tracking during a session
- APK picker that hands selected APK to Android's package installer
- GitHub Actions debug APK build

Open the folder in Android Studio and run the app configuration, or use the GitHub Actions workflow to build the APK.
