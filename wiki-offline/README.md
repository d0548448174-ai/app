# ויקיפדיה אופליין — Android APK

אפליקציית קורא ZIM באנדרואיד שמציגה ערכי ויקיפדיה בלי חיבור לרשת. הקורא מבוסס על Kiwix Android, מנוע קוד פתוח שמסוגל לפתוח קובצי ZIM, והשינוי המקומי מסיר תמונות מתוכן הערכים.

## מאגר שמצורף לבנייה

- קובץ: `wikipedia_he_all_mini_2026-07a.zim`
- גודל ברישום המקור: כ־782 MiB
- תכולה: ההקדמות ותיבות המידע של ערכי ויקיפדיה בעברית; גרסת mini, לא הטקסט המלא של כל ערך.
- מקור: [אינדקס קובצי ZIM של Kiwix](https://download.kiwix.org/zim/wikipedia/)

הקובץ אינו נשמר ב-Git כדי לא להעלות מאות מגה־בייט להיסטוריית המאגר. תהליך GitHub Actions מוריד אותו בזמן הבנייה ומכניס אותו ל-APK.

## בנייה והתקנה

דחיפה של השינויים לענף `wiki-offline-android` מפעילה את GitHub Actions. בסיום מוצג Release ניסיוני עם `Wikipedia-Offline-HE.apk` וקובץ `build-info.txt` הכולל hash של ה-APK.

ה-APK יהיה גדול מאוד כי הוא כולל את מאגר ה-ZIM. בהפעלה הראשונה מתבצעת העתקה חד־פעמית של המאגר לאחסון המכשיר. צריך מקום פנוי נוסף עבור העותק; מומלץ להשאיר לפחות כ־1.6GB פנויים, להמתין להשלמת ההעתקה ואז לפתוח מחדש את האפליקציה אם הספרייה עדיין לא מציגה את המאגר.

## מימוש

- בסיס: [Kiwix Android](https://github.com/kiwix/kiwix-android), רישיון GPL-3.0-or-later.
- שם האפליקציה מותאם לעברית.
- מאגר ה-ZIM מצורף ל-APK ונפרס אוטומטית ל-`Android/media` של האפליקציה.
- טעינת תמונות נחסמת ותמונות/וידאו ורקעים גרפיים מוסרים מתוכן הערכים.
- GitHub Actions בונה את וריאנט `debug` (חתום במפתח debug לצורך התקנה ובדיקה) ומעלה APK ל-Releases.

## מגבלות

זו גרסת ניסוי. היא אינה מהדורה רשמית של קרן ויקימדיה או Kiwix. מאגר ה-mini אינו כולל את מלוא הטקסט של כל הערכים, והעדכון של המאגר מחייב בנייה חדשה עם קובץ ZIM חדש.
